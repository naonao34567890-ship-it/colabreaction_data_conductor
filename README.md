# 分子 XYZ ライブラリ ＋ 分子エディタ

## 起動

1. ソースを取得し、`dist` と `tests` のあるプロジェクト直下でターミナルを開きます。
2. `python -m http.server 8000 --bind 127.0.0.1` を実行します（Windowsでは `py -m http.server 8000 --bind 127.0.0.1` でも可）。
3. ブラウザで `http://127.0.0.1:8000/dist/index.html` を開きます。
4. 終了時はターミナルで Ctrl+C。`file://` による直接起動は使わないでください。

バックエンド処理・アカウント登録は不要です。このローカルサーバは静的ファイルを配信するだけです。分子はブラウザのIndexedDBに保存します。3D描画用Three.js 0.170.0はCDNから読み込むため、初回を含めインターネット接続が必要です。

## ファイル

- `index.html`：ライブラリ、登録キュー、ファイル／フォルダ登録、出力ダイアログ
- `editor.html`：3Dエディタ、投げ縄・原子選択、移動・回転、交換、追加、保存
- `common.js`：XYZ解析、元素・結合、IndexedDB、共有3D描画、仮想グリッド
- `worker.js`：classic Web Worker。登録解析・バッチ保存、ZIP/ZIP64/連結XYZ出力。Worker不可時は同じ処理を小分けで実行
- `REQUIREMENTS.md`：全58要件IDと補足仕様の自己点検
- `VALIDATION.md`：実行した検証、未検証の範囲、仮定・制限
- `tests/`：Node.jsテスト、ブラウザ負荷テスト、QM9の例

## 使い方

ファイル・フォルダをライブラリへドロップ、または上部ボタンで選択します。タイルをクリックして選択し、「全選択」は画面外も含めて選択します。ダブルクリックまたは「エディタで開く」で別タブを開きます。

エディタでは Ctrl＋クリックで原子を選択、Ctrl＋Alt＋クリックで特別な点を指定します。W/A/S/D、Space、Shiftで移動、Alt＋左ドラッグで回転します。投げ縄ON時は左ドラッグが投げ縄になり、Ctrl併用は追加選択です。操作一覧はエディタ右下にもあります。

「1に登録」「2に登録」でモイエティとそれぞれの特別な点を記憶します。交換は並進のみで、原子の番号・元素・行順を保持します。両方に点がある場合は点、なければ重心を交換の基準にします。

右の縮小ライブラリから選択した1分子を追加できます。追加分の全原子が選択され、番号は末尾に続きます。編集結果の保存は常に新規分子として行います。未編集の分子は元のコメント・追加列・フッターを含む原文で出力し、座標編集後はコメントのみ保持した標準XYZにします。

## 大量データ時

- ジョブは1画面内で逐次処理。別ドロップは待機キューに入ります。
- フォルダ列挙はメインスレッドのDirectory APIで明示スタックを使用し、`readEntries`が空になるまで繰り返します。ファイル内容はWorkerが読みます。
- 8ファイル以下のまとまりでWorkerへ渡し、Worker内の実読み込みは1本。256 KiBずつ読みます。1ファイル50 MiB超はスキップします。
- 通常200分子ごとに書き込みます。極端に大きい分子が混ざる場合は推定32 MiBの待機バッファ制限を優先して早期コミットします。最後の端数・キャンセル時の端数も保存します。
- 2,000ファイル超は走査終了後に実数を表示し、続行／中止を確認します。
- サムネイルは見えているタイルだけ生成し、160×160 PNGのBlobをキャッシュ。画面外のBlob URLは解放します。
- ZIPは無圧縮STORE方式、UTF-8ファイル名、ZIP64対応です。1分子ずつ読み込み、出力先の書き込み完了を待って次へ進みます。
- File System Access API対応ブラウザでは保存先に直接書き込みます。非対応時はBlobダウンロードになり、出力が512 MiBを超える場合は分割を案内して中止します。無制限にメモリを消費しないための制限です。
- 10,000分子超の出力では容量・時間の概算を示して確認します。時間は端末により変わります。
- 登録中も一覧のスクロール・選択・エディタ起動は使えます。登録とダウンロードの進捗が衝突しないよう、登録中の新規ダウンロード開始は無効、ダウンロード中の登録ジョブは待機します。

## 保存について

同じブラウザ・同じプロファイル・同じオリジン（URLのホスト名とポート）で開いてください。`localhost` と `127.0.0.1`、ポート8000と8001は別の保存領域です。ブラウザのサイトデータを消すと分子も消えます。必要なデータはXYZ/ZIPで書き出してください。

## 検証を再実行

Node.js 20以降がある場合、`node tests/test.cjs`。標準ライブラリのみを使用します。

起動中に `http://127.0.0.1:8000/tests/browser-tests.html` を開くと、合成3000ファイルのWorker登録・キャンセルと、13万件メタデータの仮想スクロールを試せます。登録テストは同じブラウザのライブラリに `QA_…` のテスト分子を追加します。独立したブラウザプロファイルまたは別ポートで実行してください。

## 検証の限界

合成3000ファイル、13万件の軽量一覧、65536件ZIP64は確認済みですが、QM9全約13万ファイルを一度に実登録する試験は未実施です。この作成環境ではWebGLが無効で、3D表示・原子のマウス操作・サムネイルキャッシュの実画面確認はできませんでした。全要件の実機受け入れ完了を保証するものではありません。詳細は `VALIDATION.md` を参照してください。
